📸 User Manual

Photobooth v2
Operator Guide

Everything you need to operate the booth, customise the look, adjust print settings, and keep sessions running smoothly.

🖥️ Platform: Raspberry Pi 4B 🖨️ Printer: Epson L3252 🐍 Runtime: Python 3 · Kivy 📄 Output: 4×6 inch photo print
🏠

Overview

What the photobooth does and how it is structured

The photobooth captures 4 photos in a timed sequence, applies a film-style colour filter, and prints a 4×6 sheet with two identical side-by-side photo strips — a classic photo-strip format. Users can choose one of several filters and, if they wish, retake the sequence once.

📷

4-Photo Sequence

The booth captures 4 photos with a 3-second countdown before each shot. A flash effect fires on capture.

🎨

Filter Selection

After capture, users pick a filter — Fuji (pink/warm film look) or Sepia (vintage warm tone).

🖨️

4×6 Print

Two strips are printed side-by-side on a 4×6 borderless sheet via the Epson L3252.

🔁

One Retake

Users get one opportunity to retake all 4 photos before being locked in to the print screen.

▶️

Operating the Booth

Step-by-step guide for a complete session

1

Power On

Turn on the Raspberry Pi and the Epson L3252 printer. Wait for the Pi to fully boot into the desktop. The photobooth script starts automatically (or run it manually with python main.py).

2

Welcome Screen

The booth displays the welcome.png background. Tap the invisible start button (the lower-centre region of the screen) to begin a session.

3

Photo Sequence — 4 Shots

The live camera preview appears. For each of the 4 photos: "POSE!" is displayed, followed by a 3-second countdown rendered in the Didot font. The screen flashes white on capture. The sequence repeats 4 times automatically. Captures use the camera's original (non-mirrored) orientation by default — see MIRROR_CAMERA in Settings.

4

Filter Selection (First Visit)

The filter.png screen is shown with the two processed strips previewed. Two filter buttons are available. Tap a filter to switch — it processes in the background. A retake button (✕) is visible in the top-left. A Print button is at the bottom-right.

5

Optional: Retake

Tap the ✕ button to retake all 4 photos. This uses the single available retake. After retaking, the filter_selection_print.png screen is shown — identical buttons but without the retake option. No further retakes are possible.

6

Print

Tap the Print button. The thankyou.png screen is displayed while the image is processed and sent to the printer. The final 4×6 image is not saved to the gallery/ folder by default — set SAVE_PIC = 1 in Settings to enable that.

7

Reset

After GOODBYE_SCREEN_SECONDS (30 seconds by default), the booth automatically returns to the welcome screen, ready for the next group. The retake counter is reset.

Settings File

How to use settings.py

All adjustable constants live in settings.py in the same folder as the main script. You never need to edit main.py to change how the booth looks or behaves — everything is controlled from this one file, and it's imported directly into main.py. Filter effect code itself (the actual colour/tone processing) lives separately in filters.py — see the Filters section.

💡
Edit settings.py and restart the app to apply changes. No reboot needed — just close and re-run python main.py.
settings.py — minimal example 
# Disable printing for a test run
PRINT_PIC = 0

# Make borders slightly bigger
BORDER_TB_MM = 6.5

# Mirror the camera image (default is the original, non-mirrored view)
MIRROR_CAMERA = False

# Turn off yellow debug buttons (production)
DEBUG_BTN_COLOR = (0, 0, 0, 0)
📋

All Settings Reference

MIRROR_CAMERA False Whether the captured photo is horizontally flipped. False keeps the camera's true, original orientation. Set to True to mirror it like a selfie cam.
COUNTDOWN_FONT_PATH assets/fonts/Didot.ttf Path to the font used for the on-screen countdown ("3, 2, 1"). Defaults to a Didot font file — see the Didot font setup instructions supplied with the project.
BG_WELCOME welcome.png Filename of the idle/welcome screen background, relative to assets/. Swap in a new welcome screen by just changing this filename.
BG_FILTER_SELECT filter.png Filename of the filter-selection screen shown on the first attempt, while a retake is still available.
BG_FILTER_SELECT_NO_RETAKE filter_selection_print.png Filename of the filter-selection screen shown after the one retake has been used (no retake button area needed on this image).
BG_THANKYOU thankyou.png Filename of the thank-you / printing screen background.
OVERLAY_ENABLED False Turns the paper texture overlay on the final print on or off. Off by default.
OVERLAY_PATH paper_overlay0.png Filename of the overlay image, relative to the assets/ folder. Change this to point at a different overlay texture without touching main.py.
OVERLAY_OPACITY 0.35 Overlay strength used only when OVERLAY_ENABLED = True. 0.0 = invisible, 1.0 = fully opaque.
ROW_GAP 15 Vertical pixel gap between each of the 4 stacked photos on the strip. See Strip & Layout.
CORNER_RADIUS 10 Rounded corner radius on each individual photo. See Strip & Layout.
STRIP_W 600 Width of a single photo strip canvas in pixels. See Strip & Layout.
STRIP_H 1800 Total height of a single photo strip in pixels. See Strip & Layout.
BORDER_SIDE_MM 3.0 Left/right border bleed in mm. See Borders & Print.
BORDER_TB_MM 6.0 Top/bottom border bleed in mm. See Borders & Print.
H_OFFSET_MM 0 Horizontal shift to compensate for uneven overspray. See Borders & Print.
STRIP_GAP_MM 2.0 Width of the solid black gap between the two strips. See Borders & Print.
DPI 300 Print resolution in dots per inch. See Borders & Print.
PRINT_PIC 1 Whether the final image is sent to the printer. See Print & Save.
SAVE_PIC 0 Whether a copy is saved to gallery/. Off by default. See Print & Save.
GOODBYE_SCREEN_SECONDS 30.0 How long the thank-you/goodbye screen is shown before the booth automatically resets to the welcome screen.
DEBUG_BTN_COLOR (1, 1, 0, 0) RGBA colour of all invisible touch buttons. See Debug Mode.

Strip & Layout Settings

Control photo dimensions, gaps, and corner style

📷

Photo Strip Layout

ROW_GAP 15 Vertical pixel gap between each of the 4 stacked photos on the strip. Set to 0 for no gap, increase for breathing room.
CORNER_RADIUS 10 Rounded corner radius on each individual photo. 0 = sharp square corners. 30 = very rounded.
STRIP_W 600 Width of a single photo strip canvas in pixels. Both strips share this width. Affects aspect ratio of each photo frame.
STRIP_H 1800 Total height of a single photo strip in pixels. Default of 1800 px aligns with the 4×6 canvas at 300 DPI.
⚠️
Changing STRIP_W or STRIP_H affects the aspect ratio of the photos on the printed strip. Only change these if you also adjust the print canvas dimensions.
🖨️

Borders & Print Settings

Control print margins, alignment, and DPI

All values below are in millimetres (mm). They are converted to pixels automatically using the DPI setting at print time. The Epson L3252 oversprays the paper edges in borderless mode — these border settings act as a bleed buffer to protect your content from being cut off.

📏

Border & Gap Controls (mm)

BORDER_SIDE_MM 3.0 Black border on the left and right edges of the 4×6 canvas. Increase if content is being cropped on the sides.
BORDER_TB_MM 5.0 Black border on the top and bottom edges. Larger than side border to compensate for the printer's stronger vertical overspray. Increase if top or bottom is still cut off.
H_OFFSET_MM 0 Horizontal shift applied to both strips. Negative = shift left (right border grows). Positive = shift right (left border grows). Adjust in 0.5 mm steps after test prints.
STRIP_GAP_MM 2.0 Width of the solid black vertical gap between the left and right photo strips. This is the centre divider on the 4×6 sheet.
DPI 300 Print resolution in dots per inch. 300 DPI is standard for a 4×6 photo print. Do not change unless switching paper size or printer.
ℹ️
Tuning tip: Print a test sheet and measure the actual border widths with a ruler. If the right border is 1 mm wider than the left, set H_OFFSET_MM = 0.5. If the top border is 2 mm larger than the bottom, increase BORDER_TB_MM by 1.

Print & Save Options

Toggle printing and gallery saving independently

🖨️

Output Controls

PRINT_PIC 1 Controls whether the final composited image is sent to the Epson L3252 for printing.
SAVE_PIC 0 Controls whether the final composited image is saved to the gallery/ folder on disk for record-keeping. Off by default — set to 1 to enable saving a copy of every print.
ValueMeaningUse case
1 Enabled ✓ Normal operation — print or save as expected.
0 Disabled ✗ Testing mode — skip the action without errors. Useful for testing the UI without wasting paper or filling up storage.
💡
Set PRINT_PIC = 0 when positioning buttons or adjusting the UI. This prevents the printer from being triggered on every test run.

Debug Mode

Making invisible buttons visible during layout work

All interactive buttons are transparent in production so they sit invisibly over artwork created in Canva. During layout work, set DEBUG_BTN_COLOR to a semi-transparent yellow so you can see exactly where each button is and adjust its position and size in the code.

🟡

Button Colour Setting

DEBUG_BTN_COLOR (1,1,0,0.3) RGBA colour tuple applied to all invisible touch buttons. Format: (Red, Green, Blue, Alpha) — values 0.0 to 1.0.
settings.py 
# Debug — show buttons as semi-transparent yellow
DEBUG_BTN_COLOR = (1, 1, 0, 0.3)

# Production — fully invisible buttons
DEBUG_BTN_COLOR = (0, 0, 0, 0)

Each button's size_hint and pos_hint values in the code correspond to fractions of the screen (0.0 – 1.0). Adjust these values while DEBUG_BTN_COLOR is active, then set it back to invisible for the final build.

Background Images

The PNG screens shown at each stage of the session

All background images live in the assets/ folder. They are full-screen PNGs sized to 1024 × 600 px (the screen resolution). Design them in Canva or any tool, export as PNG, and drop the file into the assets folder.

The filenames themselves are no longer hardcoded in main.py — each screen's filename is a setting in settings.py. To swap an image (e.g. give the welcome screen a seasonal redesign), just rename your new PNG and update the matching setting below — no code changes needed.

settings.py — background images 
# Idle / welcome screen
BG_WELCOME = "welcome.png"
# Filter selection screen — shown on first attempt (retake available)
BG_FILTER_SELECT = "filter.png"
# Filter selection screen — shown after the retake has been used
BG_FILTER_SELECT_NO_RETAKE = "filter_selection_print.png"
# Thank-you / printing screen
BG_THANKYOU = "thankyou.png"
⚠️
File names are case-sensitive. welcome.png and Welcome.png are treated as different files — whatever you type into settings.py must match the actual file in assets/ exactly.

Paper Overlay

Optional texture layer applied on top of the final print image

The paper overlay is a transparent RGBA PNG that can be composited on top of the finished 4×6 image before saving and printing, to add a subtle paper grain or texture effect. It is now controlled by a dedicated on/off switch in settings.py, and is off by default — when disabled, the overlay image isn't even loaded at startup.

📄
paper_overlay0.png
assets/

RGBA PNG texture. Applied on top of the final 4×6 canvas before printing, only when OVERLAY_ENABLED is True. The filename is set by OVERLAY_PATH — swap in a different texture file without editing main.py.

The overlay is turned on and tuned entirely from settings.py:

settings.py — overlay controls 
# Turn the paper overlay on or off entirely
OVERLAY_ENABLED = False

# Overlay image filename, relative to assets/
OVERLAY_PATH = "paper_overlay0.png"

# Only used when OVERLAY_ENABLED is True
# 0.0 = fully invisible, 1.0 = fully opaque overlay
OVERLAY_OPACITY = 0.35
💡
To enable the overlay, set OVERLAY_ENABLED = True in settings.py and tune OVERLAY_OPACITY to taste. To add a subtle film grain, scan a piece of aged paper and save it as an RGBA PNG — start with opacity around 0.1–0.15.

Filters

Available colour filters and how to tune them

All filter code now lives in its own file, filters.py — one function per filter (apply_fuji(), apply_sepia(), apply_bw()) plus a shared apply_filter(work, mode) dispatcher that main.py calls during process_background(). All filter parameters are commented inline in filters.py — find the filter you want to tune and adjust the values directly there. main.py itself no longer contains any filter logic.

Fuji 🌸

Warm pink film aesthetic. Applies a pink tint matrix, soft haze lift, warm white overlay blend, reduced brightness and contrast, and a subtle bloom glow. White/cream canvas background on the strip.

Default filter

Sepia 🕰️

Vintage warm tone. Aggressive highlight recovery, matte shadow lift, classic sepia matrix conversion, and optional oval vignette and horizontal bar effects. Black canvas strip background.

Dark strip

B&W 🎞️

High-contrast black and white with a subtle red-brown tint matrix, increased sharpness, and film grain. Currently available in the code but not wired to a UI button.

Unlisted
ℹ️
Tuning filters: All adjustable values inside each filter block have inline comments explaining what each number does. For example, in the Fuji filter: np_work + 5 controls haze intensity — lower = less haze, higher = more milky. The colour matrix values control individual RGB channel boosts.

Troubleshooting

Common issues and how to fix them

🖨️ Printer shows "waiting for printer to become available"

The usblp kernel module is conflicting with CUPS. Run:
echo "blacklist usblp" | sudo tee /etc/modprobe.d/blacklist-usblp.conf
sudo modprobe -r usblp && sudo systemctl restart cups
This is a permanent fix — the module will not reload after reboot.

📐 Print has white borders instead of being borderless

The media type T4X6FULL (Trimless/Borderless) must be used. Verify the printer queue name with lpstat -p and check that your PPD supports this size via lpoptions -p L3250-Series -l | grep PageSize. The print command in the code already uses T4X6FULL.

✂️ Content is being cut off on the edges

The printer oversprays by ~2 mm in borderless mode. Increase BORDER_TB_MM or BORDER_SIDE_MM in settings.py to add more bleed buffer. Start with BORDER_TB_MM = 6.0 and print a test.

⬅️ One border is larger than the opposite border

Uneven overspray from the printer. Use H_OFFSET_MM in settings.py to shift the strips horizontally, or adjust BORDER_TB_MM vertically. Adjust in 0.5 mm steps and reprint.

🔵 Sepia black tones turn navy blue after a week

The printer is using a CMY ink mix instead of pure black ink for near-black pixels. In apply_sepia() in filters.py, add a black mask to force shadow pixels to pure (0,0,0) before printing. Also ensure you are using genuine Epson ink cartridges — third-party inks fade unevenly.

📷 Camera not detected on startup

Ensure the camera ribbon cable is firmly seated. Run rpicam-hello in the terminal to verify the camera is accessible. The app will call safe_exit() automatically if Picamera2 fails to initialise.

Danger Zone

Destructive terminal commands — read the warnings before running anything here

☠️
Read this before you touch the terminal. Every command on this page is destructive and cannot be undone. They are meant for a stuck booth during an active event, not routine use. If you are not sure what a command does, do not run it — ask someone who does, or restart the whole Pi instead (sudo reboot) rather than guessing.
🖨️

Cancel All Print Jobs

cancel -a Cancels every pending and active print job in the CUPS queue for all printers on the system — not just the current job.
terminal — cancel every queued print job 
# Cancels ALL jobs on ALL printers, queued and in-progress.
# There is no confirmation prompt and no undo.
cancel -a

# To target only the Epson L3252 queue instead of every printer:
cancel -a L3250-Series
⚠️
Caution: cancel -a with no printer name clears jobs on every configured printer, not just the booth's Epson L3252. If a print is already physically feeding through the printer when you cancel it, the printer may still finish that physical sheet or jam mid-print — clear the paper path afterward if needed. Only run this if prints are visibly stuck or duplicating; it will not recover a job you actually wanted.
🛑

Force-Kill the Booth Application

pkill -9 -f main.py Immediately kills the running photobooth process (and any of its child threads) with no cleanup.
terminal — force-kill everything 
# Force-kills the photobooth app. SIGKILL — no graceful shutdown,
# camera handle and GPU/display resources are NOT released cleanly.
pkill -9 -f main.py

# If the camera then refuses to reopen ("device busy"), also clear
# any leftover picamera2/libcamera process before relaunching:
pkill -9 -f libcamera
☠️
High caution: pkill -9 sends SIGKILL — the app is terminated instantly with no chance to close the camera, finish writing a file, or shut down cleanly. Possible side effects: a half-written JPEG in gallery/ or reports/, or the camera left in a locked state that blocks the next launch until the Pi is rebooted. Prefer closing the app normally (press Esc — this calls safe_exit() and releases the camera properly) or sudo reboot whenever either option is available. Only reach for pkill -9 when the app is fully frozen and unresponsive to Esc.
🔌

Shut Down the Raspberry Pi

sudo poweroff Cleanly shuts down and powers off the Pi. Wait for the green activity LED to stop blinking before cutting the power at the wall.
terminal — power off the Pi 
# Shuts down the entire Raspberry Pi, not just the app.
# All unsaved work and open sessions are lost.
sudo poweroff
☠️
High caution: sudo poweroff shuts down the entire Pi, not just the photobooth app — the booth will go completely dark and stay off until someone is physically present to reconnect power and boot it back up. Never run this mid-event unless you intend to end the session entirely (e.g. packing up at the end of the night). If you just need to restart the software, close the app with Esc instead, or use sudo reboot if the Pi itself needs a fresh boot but should come back online automatically.
